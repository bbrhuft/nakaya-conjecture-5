# Direct verification at square levels

The report explains the complete direct enumeration of supersingular coarse points on the Fricke quotients at levels 9, 25 and 49. This package is separate from the earlier characteristic-zero fixed-point verifier and uses no class numbers or modular-form traces. The manuscript itself is unchanged.

The required runtime is PARI/GP 2.15 or later; the executed version was 2.15.4. The Python audit uses Python 3 and its standard library only. All input data are generated by the program. No external imports, modular-polynomial tables, downloads, or companion repositories are needed.

For the default survey through 300, run in this directory:

```sh
gp -fq -s 512000000 verify_square_direct.gp > baseline.log 2>&1
```

For the extended survey through 1000:

```sh
gp -fq -s 512000000 <<'GP' > extended.log 2>&1
SD_MAXP=1000;SD_OUT="square_extended.csv";setrand(20261026);
read("verify_square_direct.gp");
GP
```

For the separately selected larger primes:

```sh
gp -fq -s 512000000 <<'GP' > heldout.log 2>&1
SD_PRIMES=[1009,2003,5003];SD_OUT="square_heldout.csv";setrand(20261027);
read("verify_square_direct.gp");
GP
```

Then run the coverage and result audit:

```sh
gp -fq -s 512000000 verify_middle_pairs.gp > middle_pairs.log 2>&1
gp -fq audit_snapshots.gp > snapshot_audit.log 2>&1
python3 audit_square_results.py > verification_audit.log
```

The second enumeration uses unordered pairs of distinct order-ell subgroups on the middle curve. It does not use the main verifier's Vélu or dual-isogeny routines. Its starting supersingular set and prime-order kernel enumeration are shared. `Prime_Square_Cartan_Proof.md` supplies the classical-moduli interpretation and a direct proof of the prime-square formula, without a priority claim.

The main GP entry point catches errors and exits with status one. The Python audit also rejects missing or duplicate cases, checks the expected ranges, compares the repeated baseline with the extended run and verifies the special-automorphism fibre counts. Complete CSV coverage is required even if console output is buffered or truncated by a runner. The baseline CSV retains an earlier spelling `rational_Frike_fixed`; the audit accepts that spelling and the corrected `rational_Fricke_fixed`.

To run one case interactively without launching a survey:

```gp
SD_NO_RUN=1;
read("verify_square_direct.gp");
sd_check(13,7)
```

To retain every coarse point and its Frobenius and Fricke images:

```gp
sd_check(13,7,"example_p13_ell7.gp")
```

The snapshot is standalone GP data. `SS_J` holds the supersingular invariants. Each row of `POINTS` is `[source_j_index, kernel_polynomial, Frobenius_image_id, Fricke_image_id]`, with indices starting at one. Its field definition and explicit coefficient coercion permit exact reloading.

`Direct_Square_Level_Appendix.tex` is a proposed manuscript insertion using the manuscript's existing macros. Its opening comment supplies the additional bibliography entry `MMP2025`, which should be added inside the article's existing bibliography. It summarizes the new evidence; it does not alter the article. The report states the finite range and the limitations explicitly.
